Cherimoya SSH

基于 Tauri v2 与 Rust 构建的桌面 SSH 客户端。 多标签终端、SFTP 文件管理、拖拽上传，都在同一个窗口里完成。

核心功能

日常运维真正会用到的那几件事，都做完了。

主机分组管理

按类别整理服务器，添加、编辑、删除都在侧边栏完成。配置自动写入本地 hosts.json，重装也不丢。

多标签页终端

同时打开多个 SSH 会话，标签页之间自由切换，互不干扰。右键标签页还能直接复制出一个同样的连接。

SFTP 文件传输

终端旁边直接浏览远程目录，上传下载不用另开工具。浏览、建目录、删除都在同一个面板里。

拖拽上传与进度

把文件拖进窗口就开始传输，实时显示进度条。传大文件时心里有数，不用盯着终端猜。

自定义窗口栏

隐藏系统原生边框，标题栏自己画：最小化、最大化、关闭，拖动即可移动窗口，Windows 与 macOS 观感一致。

终端自适应缩放

终端区域随窗口大小自动调整，并通过 ResizeObserver 同步 PTY 尺寸，窗口拉伸后不会错行。

技术架构

Rust 负责连接，Vue 负责界面，两边通过 Tauri 事件流对接。

Desktop Tauri v2轻量级桌面应用框架，包体积小
Frontend Vue 3 + TypeScript + Vite响应式 UI，开发时热更新
Terminal xterm.js高性能终端模拟器
SSH russh + TokioRust 异步 SSH 协议实现
SFTP russh-sftpRust SFTP 客户端
cherimoya — 从源码运行
# 克隆仓库
$ git clone https://github.com/binfenshengdai/CherimoyaSSH.git
$ cd CherimoyaSSH
 
# 安装前端依赖
$ npm install
 
# 启动完整应用（Vite 热更新 + Rust 后端）
$ npm run tauri dev

需要 Node.js ≥ 18 与 Rust stable。打包发布版本用 npm run tauri build， 产物在 src-tauri/target/release/bundle/。
